# Контекст для следующего ИИ-агента

- Задание: тема 2 из `sources/task.md`; критерии журнала — `sources/experiment_design.md`; учебный образец PyTorch — `sources/lstm_forecaster.py`. Рабочее описание — `plan.md`, запуск — `README.md`.
- Данные: OpenML ID 46214, версия 15; компактный Parquet скачивается напрямую в `data/source/` вместо большого ARFF через `fetch_openml`. В память читаются только date и value_0. Анонимный клиент `value_0`, Португалия (точный регион неизвестен), 2013–2014. Исходно 15-минутная мощность в кВт; цель — энергия за следующий час в кВт·ч (сумма четырёх значений × 0,25 ч). У источника особые правила перехода на летнее время.
- Хронология: train до 2014-06-01; validation до 2014-09-01; далее forecast/test до конца 2014. Каждый **отдельный запуск** проходит train → выбор лучшей эпохи/early stopping по validation → оценку на forecast. Между запусками «победителя» не выбираем; forecast считается для каждого запуска. Прогноз пошаговый на 1 час по фактическому прошлому. Нормализация обучается только на train; метрики MAE/MSE/R² — на исходной шкале. Baselines: последний час, тот же час вчера и неделю назад.
- Файлы: `src/prepare_data.py` показывает прогресс и создаёт `data/{source,raw,processed,train,validation,forecast}/`, `data/metadata.json`, `data/README.md`; `src/lstm_core.py` — окна, LSTM, обучение и метрики; `src/experiment.py` — PyQt GUI, CSV, PNG и HTML (шаблоны в `templates/`); `src/experiment_viewer.py` — просмотр и подтверждённое удаление одного запуска без удаления общих данных. Артефакты: `experiments/weights/`, `experiments/experiments.csv`, `experiments/graphs/<experiment_id>/` (PNG, полные числовые CSV для графиков, manifest.json), `experiments/reports/`. CSV-журнал связывается с графиками через experiment_id; GUI без эмодзи.
- Установка в PowerShell: `python -m venv .venv`; `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` (в том числе pyarrow); запуск `.\.venv\Scripts\python.exe src\experiment.py` (при необходимости сам подготовит данные). Реальное скачивание/обучение/GUI проверять отдельно; не утверждать о полной работоспособности без соответствующего теста.
