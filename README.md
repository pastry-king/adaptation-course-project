# Курсовой проект: прогнозирование кредитования с помощью LSTM

Краткая карта проекта для продолжения работы:

- [`task.txt`](task.txt) — текст исходного задания по теме LSTM; [`Темы.pdf`](Темы.pdf) — исходный документ с темами.
- [`plan.txt`](plan.txt) — согласованный план проекта: что прогнозируем, с чем сравниваем и какие этапы впереди.
- [`reports/`](reports/) — результаты промежуточных этапов и выводы для следующего этапа. Начать с [`01_data_reconstruction.md`](reports/01_data_reconstruction.md); подробности по источникам и ограничениям — в [`data_audit.md`](reports/data_audit.md).
- [`data/`](data/) — данные и правила их получения: исходные книги ЦБ в `raw/`, подготовленный ряд в [`processed/monthly_credit_history.csv`](data/processed/monthly_credit_history.csv), скрипт восстановления [`build_credit_history.py`](data/build_credit_history.py). Описание столбцов и воспроизведения — в [`data/README.md`](data/README.md).
- [`sources/`](sources/) — учебные материалы, полезные конспекты, примеры кода и презентация. Это справочные знания для реализации, **не** исходные данные кредитования.

Если вы продолжаете проект в новой сессии, сначала прочитайте `task.txt`, `plan.txt` и последний отчёт в `reports/`, а затем при работе с данными — `data/README.md`. Сейчас завершён этап восстановления месячного ряда; анализ ряда и обучение модели ещё не выполнены.
