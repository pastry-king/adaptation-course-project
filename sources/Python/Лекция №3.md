В питоне все есть объект. Даже переменные int!

Класс != объект, но при создании класса создается какой-то внутренний объект класса.

Класс примерно считаю тогда свой тип переменной.

resnet - это объект

переменная указывает на объект класса, в классе есть атрибуты, которые тоже объекты класса и т.д. Короче - вложено

Функция - тоже объект. Ее можно положить в функцию или в атрибут
Каждый вызов функций создает локальное пространство имен. Вложенная функция работает со своей собственной переменной x

__init__ описывает конструктор
Пакеты и модули скачиваются pip install
Import можно полностью пакет или только модуль пакета
