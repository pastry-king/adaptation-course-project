
# Задачи классификации

Основные задачи машинного обучения с учителем:
- классификация
- регрессия

Обучение с учителем используется, когда нужен определенный результат (ответ) по данному объекту, и есть пары объект-ответ.

Классификация - раздел машинного обучения. Цель - построить алгоритм, позволяющий классифицировать произвольный объект из исходного множества. Исходное множество - обучающая выборка.

Классифицировать объект - указать номер, класс для заданного объекта.
Классификация объекта - выданный номер или наименование класса, выдаваемый алгоритмом в результате применения его к определенному объекту.

Классификация бывает:
- Бинарная - попытка ответить да/нет
- Мультиклассовая - попытка определить конкретный класс объекта

Задача регрессии - ответ до точности получается

---

Сходство или различие объектов классификации можно определить метрическим расстоянием между ними. Если объекты можно представить как точки в n-мерном пространстве (где n - количество признаков объекта), то сходство объектов можно определить как расстояние между этими точками.

Возможные меры расстояния:
- эвклидово расстояние (чаще применяется, просто расстояние)
- квадрат эвклидова расстояния (применяется, если важны дальние расстояния)
- взвешенное евклидово расстояние (если некоторые признаки важнее других)
- Хеммингово расстояние (Сумма разностей модулей координат) (дальние расстояния влияют меньше)
- расстояние Чебышева (Максимальная разность координат)

---

Метод k-ближайших соседей. Суть: берем объект, смотрим на k его соседей. Объект относим к класс большинства соседей.

Признак непрерывный - Евклидово расстояние
Признак категориальный - Хэммингово расстояние

Простейший пример k = 1. Известные соседи - обучающая выборка.

Основные преимущества - легко интерпретировать, приемлемое качество. Проверяем в первую очередь, потом только более сложные методы.

Достоинства:
- устойчивость к выбросам и аномальным значениям
- простая программная реализация
- легкая интерпретация

Недостатки:
- нет учета предыдущего опыта
- затратный в вычислительном плане
- высокая трудоемкость (т.к. вычисляются все расстояния)
- повышенные требования к репрезентативности исходных данных

---

ИТОГО:
Среди задач машинного обучения с учителем различают два основных типа - классификация и регрессия.
Самый простой способ отличить классификацию от регрессии – спросить, заложена ли в полученном ответе определенная непрерывность (преемственность).
Сходство или различие между объектами классификации устанавливается в зависимости от выбранного метрического расстояния между ними.
Для решения задач классификации используется метод k-ближайших соседей, относящий объекты к классу, которому принадлежит большинство из k его ближайших соседей в многомерном пространстве признаков.
