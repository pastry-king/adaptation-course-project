# Интеграция С++ с Python

Python управляет ML-системой, C++ выполняет отдельный kernel
С++ для вычислительного ядра ML-системы.

Способы интеграции:
- IPC
- C ABI
- C++ API

Binding - для того, чтобы C++ файл вызывался как обычный модуль (import ...)
Преобразования на границе языков имеют стоимость (?)
Для начала необходимо установить зависимости: build-essential, cmake, python3-dev, pybind11-dev, numpy

pybind11 делает расширения (модули) Python
numpy полезен при преобразованиях массивов
Необходимо проверять корректность преобразованного типа данных в массиве

Python владеет входом данных и выходов данных в, из C++

Есть какой-то GIL

Python, numpy, C++ должны работать с одними и теми данными

При маленьких массивах overhead вызова (накладные расходы) может доминировать, на больших массивах важны копирования и пропускная способность памяти (зависимость от RAM/CPU)

Примерное использование в ML-системе:
ML model (embedding) в Python -> C++ расстояние до ближайших векторов -> Python выбирает ближайших соседей и формирует ответ

У гибридного проекта два набора зависимостей, соответственно wheel или extension под конкретную ОС/архитектуру.
Два тестирования.
API для Python и C++ ядра.
Две версии.
