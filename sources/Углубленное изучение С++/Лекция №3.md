# Стандартная библиотека, типы данных и метод программирования

Язык С - полезен как техническая основа для С++

С++ имеет свои типы данных, стандартная библиотека - часть языка, управление ресурсами связана со временем жизни объектов, низкоуровневое управление при строгой необходимости, выбранные типы данных показывают намерение программиста

От С осталось:
базовые типы данных, указатели, ссылки, классы, шаблоны, циклы, операторы и выражения
С++ привнесло: 
стандартная библиотека, типы данных для массивов

Пространство имен std - область видимости именно объектов стандартной библиотеки. Отделяет объекты библиотеки от пользовательских объектов.

using namespace std; - не используем для видимости происхождения
Не полагаемся на транзитивные include
include находится в preprocessor - компилятор сначала должен увидеть объявления
Размер типа данных даются в стандарте C++
Можно выбираться тип нужной ширины исходя из задачи
Строка в C++ - объект
Тип массива указывается один раз, и его нельзя менять
Array - неизменяемая размерность
Vector - динамический массив

Ресурс принадлежит объекту. Мы управляем не памятью, ни ссылками, ни памятью, ни указателями, ни файлами. Ресурс освобождается вместе с завершением жизни объекта, т.е. связан с scope и lifetime, теперь не зависимости от free/delete. <-- Идея RAII

Не заменяем низкий уровень - меняем точку стара. Мы из просто не используем.
В С++ сначала выбирают подходящий тип, а не способ размещения байтов в памяти.
Тип задает не только память - оно задает поведение

Copy - создается новая переменная со своим значением
Move - меняем владельца значения. Первая переменная теряет значение/становится NULL
Move = перенести данные, дает указатель на старые данные

С++ не позволяет низкоуровнево управлять железом. С++ работает с виртуальной памятью. Есть таблица трансляции, там уже переводятся в настоящие ячейки памяти ОЗУ.
