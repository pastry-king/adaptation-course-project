# Курсовой проект: прогнозирование кредитования с помощью LSTM

**Итоговая курсовая работа:** [`reports/final_coursework.md`](reports/final_coursework.md) с таблицами, графиками, формулами, источниками и выводом. **Вопрос:** улучшает ли LSTM прогноз месячного объёма новых кредитов в РФ по сравнению со значением того же месяца год назад? На проверенных 12 месяцах **нет**: см. [результаты и выводы этапа 3](reports/03_experiment_results.md). Оцениваются выдачи юрлицам/ИП и физлицам вместе, **млн номинальных руб.**; не остатки задолженности и не прибыль банка. Описание происхождения и методологических ограничений — [`data/README.md`](data/README.md) и [`reports/01_data_reconstruction.md`](reports/01_data_reconstruction.md). [`task.txt`](task.txt) — задание, [`plan.txt`](plan.txt) — план, [`sources/`](sources/) — учебные материалы.

## Установка (Python 3.10+)

В Windows PowerShell, из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest
```

`requirements.txt` содержит прямые зависимости и локальный пакет. PyTorch может потребовать отдельной установки подходящей версии для вашей платформы; для эксперимента используется **CPU**, видеокарта не нужна. Точные установленные версии вместе с seed записываются в `manifest.json` каждого запуска; при необходимости сохраните `python -m pip freeze` вместе с результатами на своей машине. Никакого API, БД и сетевых запросов для эксперимента нет. `openpyxl` требуется только для восстановления данных первого этапа.

## Запуск

```powershell
.\.venv\Scripts\python.exe -m credit_forecast.cli all --config configs/experiment.yaml
```

Вместо `all` можно отдельно запустить `analyze` (быстро: история, сезонность, крупнейшие изменения год к году) или `run` (обучение и сравнение). Параметры, диапазоны дат и список seed задаются в [`configs/experiment.yaml`](configs/experiment.yaml); менять код между опытами не требуется. По умолчанию обучается несколько небольших LSTM на CPU, полный прогон может занять время. Данные из `data/processed/` и исходные книги `data/raw/` **не перезаписываются**. При обновлении CSV обновите границы и проверьте аудит источника: `test_end` должен совпадать с последним опубликованным месяцем.

Результаты (создаются при запуске):

- `reports/generated/analysis/README.md` + PNG — обзор ряда и смены методики.
- `reports/generated/README.md` — краткое сопоставление итогов двух сценариев и критерий устойчивости.
- `reports/generated/full/README.md` и `reports/generated/current_only/README.md` — отчёты по полному ряду (с архивом) и только с января 2019 года. Таблицы CSV: валидационные опыты, тестовые прогнозы по месяцам (первый и каждый отдельный seed), метрики по seed, базовые ориентиры и прогноз следующего месяца. PNG: влияние параметров, прогнозы на тесте и кривые обучения.
- `reports/generated/*/manifest.json` — SHA-256 входного CSV, границы выборок, масштабирующие параметры, конфигурация, seed и версии ПО. `artifacts/*/seed_*.pt` и `seed_*.json` — веса **из локального запуска** и параметры для их загрузки; не загружайте чужие файлы весов.

Generated-результаты и веса исключены из Git, чтобы избежать смешивания с проверенным исходным CSV; рисунки итоговой работы сохранены отдельно в [`reports/figures/`](reports/figures/). Для публикации полных машинных результатов скопируйте нужный отчёт с `manifest.json` и исходным CSV/его хешем; передайте также `pip freeze` для точной среды. Документ об изменениях и протоколе — [`reports/02_experiment_design.md`](reports/02_experiment_design.md).
