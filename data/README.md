# История выдачи кредитов по месяцам

`processed/monthly_credit_history.csv` — **210 календарных месяцев**, апрель 2009 — сентябрь 2026. Дата в поле `month` обозначает месяц выдачи (первое число месяца), **не дату публикации**. Все денежные столбцы — **млн номинальных рублей**, без поправки на инфляцию. `total_mln_rub` = `corporate_and_ip_mln_rub` + `individual_mln_rub`.

Включены кредиты резидентам РФ: юридическим лицам и ИП (включая финансовые организации) и физическим лицам для целей, не связанных с предпринимательством. Кредиты ИП и ипотека уже включены в соответствующие части; повторно их прибавлять нельзя. Показатель — **объём предоставленных кредитов за месяц, не задолженность**. Использованы опубликованные итоги РФ по всем валютам в рублёвом эквиваленте, а не только кредиты, номинированные в рублях.

| Период | `source_method` | Как получены значения |
| --- | --- | --- |
| 2009-04 — 2018-12 (117 месяцев) | `archive_302_01M_302_02M_cumulative_difference_unverified` | Архивные таблицы [302-01M](https://www.cbr.ru/Queries/StatTable/Excel/302-01M?lang=ru-RU) и [302-02M](https://www.cbr.ru/Queries/StatTable/Excel/302-02M?lang=ru-RU), строка «РОССИЙСКАЯ ФЕДЕРАЦИЯ», столбец B «Объём → Всего». За февраль—декабрь — разность накопленных итогов на первое число следующего и текущего месяца; за январь — накопленный итог на 01.02 без вычитания прошлого года. |
| 2019-01 — 2026-09 (93 месяца) | `current_monthly_0409303_0409316` | Лист «итого», строка РФ, напрямую из книг [организации и ИП](https://www.cbr.ru/vfs/statistics/BankSector/Loans_to_corporations/01_04_D_New_loans_subj.xlsx) и [физлица](https://www.cbr.ru/vfs/statistics/BankSector/Mortgage/02_04_New_loans_ind.xlsx). |

**Важно:** на границе января 2019 года Банк России поменял формы отчётности (0409302 → 0409303, по физлицам → 0409316) и способ публикации (накопленные итоги → данные за месяц). Прямого месяца перекрытия нет; сопоставимость старого и нового периода **не доказана**. Архив не отбрасывается автоматически: рабочий вариант — использовать все 210 месяцев с отметкой методики и проверить устойчивость выводов на периоде с января 2019 (93 месяца). Архивные разности валютной части рублёвого эквивалента также требуют отдельной проверки на влияние переоценки: не считать их безусловно чистыми выдачами. Январь—март 2009 из этих архивов по отдельности не восстановить. Итоги этапа — в [`reports/01_data_reconstruction.md`](../reports/01_data_reconstruction.md), подробный аудит — в [`reports/data_audit.md`](../reports/data_audit.md).

Исходные книги лежат в `raw/` (выгрузка **15.11.2026**); при отсутствии файлов скрипт скачает актуальные версии, которые ЦБ мог пересмотреть. Для воспроизведения: `python -m pip install openpyxl`, затем `python data/build_credit_history.py`. Проверяются полнота месяцев, итоговая сумма и контрольные значения декабря 2018 и сентября 2026 (если книги уже изменились, контроль может потребовать обновления).
