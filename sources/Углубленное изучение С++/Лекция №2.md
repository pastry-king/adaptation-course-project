
Scope - область кода, где работает объект
Lifetime - временной интервал, в течение которого существует объект
Для dynamic storage объект может продолжить существовать после выхода указателя из scope
Если исчез указатель != объект исчез

Ресурс != Память. Любой ресурс надо корректно "закрыть". т.е. Acquire -> Use -> Release!!

Типы утечки памяти: 
- ошибка на уровне ОС (после убийства процесс память не вернулась)
- долгоживущий процесс занимает все больше ресурсов, но не освобождает их

RAII - Resource Acquisition is Initialization
Идея: владение ресурсом помещается внутрь объекта (конструктор и деструктор)

Деструкторы все равно работают после исключения

Есть умные указатели (unique, shared) - созданы, чтобы явно указать сколько владельцев может быть

Инвариант - условие, которое должно быть истинно для корректно существующего объекта

При исключениях, программа не должна терять ресурсы. Объекты должны оставаться корректными. RAII почти! решает проблему транзакционности.

Ошибки должны отвергать неверный вход (raise, throw)
Python освобождает от управления lifetime и ownership, но не C++
