# Сбор и подготовка данных

Цель машинного обучения – анализ данных.
Данные – зарегистрированная информация; представление фактов, понятий или инструкций в форме, приемлемой для общения, интерпретации, или обработки человеком или с помощью автоматических средств (ISO/IEC/IEEE 24765-2010).

Данные в машинном обучении – это представление информации об исследуемой задаче в виде множеств исследуемых объектов и множеств их характеристик, на основе которых строятся модели, разрабатываются подходы, методы и алгоритмы анализа для принятия решений.

Для Аналитика (Data Scientist, Data Analyst, Data Mining Engineer) очень важно обладать правильными данными, что гарантирует эффективность обработки и построении прогнозов.

Data mining (добыча данных, интеллектуальный анализ данных, глубинный анализ данных) – общее название, которое используется для обозначения множества методов обнаружения в данных ранее неизвестных, нетривиальных, практически полезных и доступных интерпретации знаний, необходимых для принятия решений в различных сферах человеческой деятельности.

Основные свойства данных:
- Доступность
- Точность
- Полнота
- Непротиворечивость
- Однозначность
- Релевантность (степень соответствия результатов поиска результатам запроса)
- Надежность (полные и точные)
- Своевременность
- Взаимосвязанность (информация о товаре, должна быть связана с информацией о клиенте)

Нарушение одного свойства - полезность данных уменьшается

Прецедент - совокупность объекта X и ответа целевой функции (target function) Y
Совокупность пар таких - обучающая выборка

Задача обучения - по выборке построить решающую функцию, которая приближала бы к целевой функции, причем на всех объектах, а не только на обучающей выборке

Решающая функция должна допускать эффективную компьютерную реализацию

Этапы решения задач машинного обучения:
1.Постановка задачи.
2.Сбор и подготовка данных.
3.Предобработка данных и выделение ключевых признаков.
4.Выбор алгоритмов машинного обучения.
5.Обучение модели (моделей).
6.Оценка качества.
7.Эксплуатация модели при достижении требуемого качества, либо возврат к одному из предыдущих шагов (перенастройка модели, добыча новых данных и т. п.).

---
ИТОГО:
- Подготовка данных – крайне важный этап анализа информации в искусственном интеллекте.
- При подготовке данных используются следующие операции: структурирование, заполнение пропусков, отбор, нормализация, кодирование.
- Многие алгоритмы машинного обучения работают только с численными данными – целыми и вещественными числами.
- Существует перечень методов, например, заполнение по медианным значениям, позволяющих восполнить пропуски в данных.
