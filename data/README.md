# Данные мини-проекта

Источник: OpenML Electricity, ID 46214, версия 15; первоисточник UCI Electricity Load Diagrams 2011–2014.
Один анонимный клиент (`value_0`), 2013–2014, время по Португалии; точный регион неизвестен.

`raw/` — 15-минутные показания мощности (кВт); `processed/` — энергия за час (кВт·ч), сумма четырёх мощностей × 0,25 ч. `train/`, `validation/`, `forecast/` — хронологические части подготовленного ряда (январь 2013 — май 2014, июнь — август 2014, сентябрь — декабрь 2014). `forecast` — отложенный тест.

Исходник искусственно сохраняет 96 отметок и на дни перевода часов; весной часть значений нулевая, осенью — суммированная. Заполнение пропусков не выполняется.
Компактный исходник Parquet при загрузке находится в `source/`; в память читаются только столбцы `date` и `value_0`.
Точные даты, числа точек, единицы и правила обработки: `metadata.json` (UTF-8).
