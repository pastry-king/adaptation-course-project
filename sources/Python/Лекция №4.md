Продолжение лекции

Есть понятие DoE - Design of Experiments
Основные понятия:
- Факторы - что меняем
- Уровни - какие значения проверяем
- Response - управляемый отклик
- Контролируемые условия - что фиксируем

Цель: минимальное количество запусков - максимум информации

Для начала делаем скрининг, ищем действительно важные факторы.
Есть стратегии какие именно факторы брать.
Основная идея: отсеиваем слабые факторы, сужаем диапазон значимых, проверяем взаимодействие - находим идеальное условие. Подтверждаем на независимых данных.
Гипотезы должны быть проверяемыми.

Типичные ошибки: 
- рандомные места выборки идкт то в train, то в test
- утечка данных, будущее идет в обучение

Еще важна воспроизводимость - поэтому фиксируем seed.

Итого регистрируем:

model_type;
