# Первая ML-модель на PyTorch

Механизм:
Данные -> Tensor -> Model -> Prediction -> Loss -> Gradient -> Parameters
Главный вопрос: как программа сама меняет числа внутри модели, чтобы ошибаться меньше?

Функции активации задаются в начале один раз, в каждом слое они обычно одинаковые

Для обучения обычно используется unsigned int 8, 16, 32, 64

Изображения - тоже числа. Изображение можно перевести в тензоры (матрицы).

Batch - модель получает не один объект. Первая размерность - количество объектов в batch
[32, 3, 224, 244] = [batch size, 3 color channels, px, py]

Dataset - на чем обучается модель, это один объект.
Dataloader - формирует из них пачки, перемешивает.

Угроза первая - отравление данных. Два вида - плохой shuffle или изначальное неправильно выбранная выборка

Loss - функция потерь. Показывает насколько сильно ошиблась модель
Тензор - матрица (набор) весовых коэффициентов для нейрона (функции активации)
Градиент - на сколько изменить весовые коэффициент, чтобы ошибка была меньше

Итерация:
Предсказание
Значение функции потерь - сравнить с target
Вычислить градиент
Изменить параметры

Эпоха обучения - количество циклов, в которых все составляющие обучающей выборки поданы на обучение

Train - изменяются параметры
Test - не изменяются параметры

Сохранить модель - сохранить параметры и слои

CPU, GPU - меняется железо, где работает код, но не алгоритм. Он один и тот же. Просто GPU просто более оптимизированы под алгебру матриц (совпало, т.к. компьютерная графика тоже на похожих матрицах работает)
Storage - CPU/RAM - Tensor - GPU/VRAM - Model

Практика:
37 классов - конечные нейроны, на значении которых принимается решение
Сети переобучены на конкретном формате данных, соответственно их надо preprocessing сделать и remapping (создать свои классы)
Дообучаем только последний слой
Accuracy = сколько изображений удалось классифицировать по выбранным классам
У нас классификатор - просто последний слой (linear head)

Уже риски - SCA, выборки, сети


Весь процесс разработки легких моделей - файл с весами + сама модель (последний слой)
