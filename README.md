# Прогноз почасового потребления электроэнергии

Мини-проект по теме 2 из `sources/task.md`. Один запуск PyQt-приложения обучает LSTM, выбирает лучшую эпоху по validation и проверяет модель на forecast; рядом приводятся три наивных прогноза. Подробный замысел — в `plan.md`.

## Запуск в Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\prepare_data.py
.\.venv\Scripts\python.exe src\experiment.py
```

Чтобы просмотреть уже записанные запуски в отдельном небольшом окне:

```powershell
.\.venv\Scripts\python.exe src\experiment_viewer.py
```

Там можно посмотреть все поля эксперимента, открыть HTML и удалить выбранный запуск после подтверждения. Удаление затрагивает только его строку в журнале, веса, отчёт и каталог графиков/числовых данных; общие исходные данные остаются. Удаление блокируется, если выполняется эксперимент или в каталоге выбранного запуска обнаружены посторонние файлы.

Подготовка данных нужна один раз. При первом запуске приложение также может сделать её автоматически, если файлов ещё нет. Загрузка компактного Parquet OpenML (~36 МиБ) показывает прогресс в консоли или журнале приложения, а в память считываются только нужные столбцы. При обрыве повторный запуск попробует продолжить скачивание. Файл можно заранее [скачать в браузере](https://data.openml.org/datasets/0004/46214/dataset_46214.pq) и положить как `data/source/electricity_46214.parquet`. Для работы после скачивания интернет не нужен. При несовместимых/неполных файлах `data/` программа останавливается, а не удаляет их.

Источник — [OpenML Electricity, ID 46214](https://www.openml.org/d/46214), первоисточник — [UCI Electricity Load Diagrams 2011–2014](https://archive.ics.uci.edu/dataset/321/electricityloaddiagrams20112014). Используются данные **одного анонимного потребителя** за 2013–2014 годы в португальском местном времени; более точный регион неизвестен. Исходные измерения мощности каждые 15 минут выражены в кВт; суммой с множителем 0,25 часа получаем энергию за час в кВт·ч. Ось X — дата/час, ось Y — кВт·ч за этот час. Набор особым образом обрабатывает дни перехода на летнее/зимнее время; см. `data/README.md` после подготовки.

| Период | Даты | Применение |
|---|---|---|
| Train | январь 2013 — май 2014 | Веса обучаются на скользящих окнах |
| Validation | июнь — август 2014 | Выбирается лучшая эпоха и ранняя остановка |
| Forecast (test) | сентябрь — декабрь 2014 | Оценка уже обученной модели |

Прогноз **на один следующий час**: на validation и forecast доступна фактическая история до предсказываемого часа; это не прогноз всего сезона из одной начальной точки. Нормализация настраивается по train, метрики MAE/MSE/R² вычисляются после возврата к шкале кВт·ч. Отдельные эксперименты не используют веса друг друга.

`src/prepare_data.py` сохраняет скачанный Parquet в `data/source/`, сырой ряд одного клиента, обработанный ряд, три выборки, `data/metadata.json` (машиночитаемое описание и фактические размеры) и `data/README.md`. `src/lstm_core.py` выполняет вычисления. `src/experiment.py` показывает прогресс и результаты; на каждый запуск создаются веса в `experiments/weights/`, одна запись в `experiments/experiments.csv`, PNG, **CSV с числовыми данными для графиков** и `manifest.json` в `experiments/graphs/<experiment_id>/`, а также самодостаточный HTML в `experiments/reports/`. Форматы описаны в `templates/README.md`. HTML содержит графики и встроенный JSON с результатами.

Для защиты: показать постановку задачи и данные, окно LSTM, три разных конфигурации (окно, слои, нейроны), сравнение с наивными прогнозами, метрики, выводы и ограничения (анонимный потребитель, DST, one-step-ahead). Более сложная сеть не обязана побеждать простой прогноз.
